Tablely

A dark VS Code theme with floating glass panels.

Context

I spend the day inside an editor, so I made one I like looking at.

Tablely is a color theme plus a set of interface customizations that turn VS Code panels into floating glass cards on a deep navy canvas.

Role

Designed and built by me. Open source.

Design

An ember palette centered on warm orange and amber, with one cool teal for contrast.

Panels
Rounded corners on panels, notifications, command palette and sidebars
Glass
Directional borders: brighter on top and left, subtle on bottom and right
Chrome
Breadcrumbs and status bar fade out until you hover them
Shapes
Pill-shaped activity bar and scrollbars

Install

Two parts: the color theme, and the CSS that creates the floating panels.

The theme installs from the VS Code Marketplace. The panel effect is applied through the Custom UI Style extension, with the steps in the README.
