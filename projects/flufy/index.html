Flufy

A community app for pet adoption and lost pets.

Context

Finding a home for a pet, or finding one that got lost, usually happens in scattered posts that disappear in a day.

Flufy puts it in one place: adoption profiles, a live map of lost pets nearby and direct chat between the people involved. It is free and run as a nonprofit.

Role

I founded Flufy and I build it.

It started in 2019 under the name Petly and went through several rewrites before it shipped. I built the Flutter app, the API behind it, the admin panel and the website.

It has been live on the App Store since April 2026 and is also on Google Play.

Product

Adopt a pet, report a lost one or publish yours for adoption, all from the same app.

Adopters send a request and talk to the current owner through in-app chat. Anyone who publishes a pet for adoption verifies their identity first.

Stack

One Flutter codebase for iOS and Android, a Node API and Firebase around it.
